# Нарезка клипов — инструкции для Claude

Этот репозиторий нужен, чтобы из длинных видео (стримы, VOD, ролики с YouTube/Twitch)
делать вертикальные клипы 9:16 для TikTok, Shorts и Reels. Пользователь пишет коротко,
например «нарежь <ссылка>, 10 клипов». Весь пайплайн ведёшь ты. Отвечай по-русски.

Перед работой: `source .venv/bin/activate` (если нет `.venv` — запусти `./setup.sh`).
Все команды: `python -m clipper <команда>`. Проект = папка `work/<имя>/`.

## Пайплайн

1. **Скачать**
   `python -m clipper fetch <ссылка> --name <коротко-латиницей>`
   - Для VOD длиннее ~3 часов, если пользователь назвал отрезок: `--from 1:00:00 --to 2:30:00`.
   - YouTube просит войти/«не бот» → попроси у пользователя `cookies.txt` и добавь `--cookies cookies.txt`.
   - Чат скачивается сам (YouTube live chat, Twitch через chat-downloader). Если чата нет — это нормально.

2. **Расшифровать речь** (по возможности)
   `python -m clipper transcribe <проект>`
   На GPU это быстро. На CPU многочасовое видео может распознаваться часами. Тогда пропусти
   этот шаг: `analyze` справится по громкости и чату, а субтитры для выбранных клипов
   при `render` распознаются по кусочку автоматически.

3. **Найти кандидатов**
   `python -m clipper analyze <проект> --top 30`
   Прочитай `work/<проект>/moments.txt`: окна, пики, речь, реакция чата.
   Если есть `transcript.txt`, ищи в нём и сам (grep по смешным/эмоциональным фразам, именам, ключевым событиям).

4. **Проверить глазами.** На каждого сильного кандидата:
   `python -m clipper frames <проект> --at <пик> --span 30 -n 6` — открой полученный jpg через Read.
   Отсеивай: меню, загрузки, AFK, повторы, моменты без понятного контекста.

5. **Один раз — координаты вебки**
   `python -m clipper frames <проект> --at <любое время с вебкой> --grid` → открой картинку,
   по красной сетке (шаг 0.1) определи `[x, y, w, h]` вебки в долях кадра.
   Потом `python -m clipper preview <проект> --at <время>` и проверь `frames/preview_*.png`:
   лицо целиком в верхнем блоке, без кусков интерфейса, субтитры не закрывают важное.
   Если вебки нет или она перекрыта — используй раскладку `blur`.

6. **Написать план** `work/<проект>/clips.yaml` (формат — `clips.example.yaml`).

7. **Смонтировать**
   `python -m clipper render <проект>` (или `--only 03-xxx` для переделки одного клипа).

8. **Проверить результат.** Из каждого готового клипа вытащи 2–3 кадра и посмотри:
   `ffmpeg -v error -ss 1 -i work/<п>/out/<id>.mp4 -frames:v 1 -vf scale=540:-2 /tmp/c.png`.
   Проверь заголовок, субтитры (ошибки распознавания → `subs.replace`), раскладку и обрезку.

9. **Отчитаться** списком: файл, длительность, формат (см. 2а), о чём клип,
   предлагаемое описание + 3–5 хэштегов.

## Как работает топовый нарезчик (самое важное)

Ты — нарезчик уровня топовых TikTok-каналов по стримерам. Клип цепляет не эффектами,
а тем, что ты **понял шутку** и подал её так, что её понимает человек, не видевший стрим.

### 1. Сначала лор, потом нарезка
- **Прочитай `transcript.txt` целиком**, а не только окна вокруг пиков громкости. Пики громкости —
  это драки и крики, а лучшие рофлы — тихие разговоры.
- Составь для себя карту лора: кто есть кто (ники из описания/лобби → как их зовут голосом),
  кто на каком герое, счёт серии, ставки (турнир, деньги), кто ушёл/пришёл на замену.
- Ищи **повторяющиеся шутки и сетап → панчлайн через всё видео** (пример: на каждом драфте
  «он меня высушит в ноль» → потом сам всех разносит). Такие клипы — лучшие: сетап из одного
  места, развязка из другого.
- Разберись, **в чём именно шутка**. Пример ошибки: «ты проиграл ставку» — это не про ставки,
  ребята прикалываются над мангеку, будто он ставил против своей команды, а у него просто свой
  турнир. Если не понимаешь шутку — не делай клип или спроси пользователя.
- Перед выбором моментов сверяй сомнительные фразы точной моделью
  (`words_in_range` с `whisper.clip_model: large-v3`) на окне с запасом ±5 с.

### 2. Хук и структура
- **Первая секунда — первая реплика бита** («Ребят, есть одна хорошая новость и одна плохая»,
  «Ты кибер какой-то?»). Без разгона, без вступлений.
- **Конец — на панчлайне** + 0.3–0.8 с реакции. Не тяни после смешного.
- **Вырезай воздух** внутри (паузы, повторы, оговорки, «ну… ну…») через `segments`.
- Длина 15–35 с. Разговорный рофл может быть и 12 с — короткие пересматривают. Цельный
  законченный диалог — до ~60 с (см. 2а).
- **Сетап → развязка из разных частей видео склеиваются встык** (`segments` в любом порядке).
  Пользователь оценил это выше всего («уровень сильного монтажёра»): например, обещание
  «сейчас всё чётенько будет» в начале видео + экран проигрыша через 16 минут + «ничего
  страшного, сейчас две игры выиграем». Ищи такие пары по всему транскрипту.

### 2а. Разнообразие подборки — каждый клип в своём формате
Цель: из одного видео 10 клипов — и все разные. Подборка из одних склеек (или из одних
кусков «как есть») однообразна. Клип — не обязательно монтаж: часто лучший клип — просто
удачный законченный кусок, например 17:23–17:55.

**Каталог форматов** (как работают топовые нарезчики; можно придумывать свои):
- **Цельный отрезок** — диалог, спор, история как есть. Вся работа — в границах.
- **Отрезок с подрезкой** — один кусок, внутри вырезаны паузы и отвлечения на игру.
- **Момент → реакция** — сначала что случилось в игре (весь экран, `layout: blur` на сегмент),
  потом лицо стримера крупно (`cam`/`crop` на сегмент). Реакция понятна, потому что видна причина.
- **Сетап → развязка** — обещание/прогноз/«правило» и его провал из разных частей видео
  («правила ставок», «Наруто ещё покажет»).
- **Переобувка / ожидание vs реальность** — уверенное мнение, а потом прямо противоположное
  («Бетбум плохая команда» → «браво, Бетбум»). Коротко, 10–15 с.
- **Суперкат** — одна и та же фраза/привычка/слово 4–8 раз подряд в быстром ритме («БКБ не
  нажал», «Наруто», «правило номер…»). Каждый кусок 1–2 с, финал — самый сильный повтор.
- **Эскалация** — 3–4 шага одной эмоции по нарастающей (надежда → сомнение → тильт →
  «на обидках создал правило, которое меня и погубило»).
- **Хот-тейк** — смелое мнение со своей логикой, сказанное уверенно («китайская дота умерла»).
  Провоцирует спор в комментариях. Только если мнение понятно без контекста.
- **Мини-гайд** — стример объясняет что-то по-своему (как выбрать арбуз, почему герой имба).
  Подпись подыгрывает: «гайд», «аналитик широкого профиля».
- **Самоирония** — стример говорит о себе, а клип показывает обратное («я тоже хорошо бью
  крипов», «как нейронка, обучаюсь»).
- **Мем-аналогия** — стример сравнивает игроков с аниме/мемом (Наруто vs Саске), клип
  строится вокруг аналогии.
- **Оффтоп / IRL** — всё не про игру: быт, еда, «во сколько я встал», внезапный арбуз в кадре.
- **Диалог с чатом/донатом** — вопрос из чата и ответ. Если вопрос не прозвучал голосом —
  коротко надписью `text:` на первом сегменте.
- **Сжатая история** — длинный рассказ (3–5 мин) ужат до 30–45 с через много подрезок,
  сохраняя завязку, поворот и концовку.
- **Петля** — конец клипа подводит к его началу (та же фраза, тот же кадр), и ролик
  пересматривается по кругу. Хорошо для 8–15-секундных рофлов.
- **Лицо** — 5–10 с чистой мимики без слов (шок, фейспалм, тихий смех) после короткой
  причины. Мем-формат, подпись делает всю работу.

**Правила подборки:**
- Перед нарезкой составь **сетку подборки**: id, формат, тема, длина, раскладка, тип хука,
  формула подписи. Покажи её себе и проверь на повторы.
- Два клипа одного формата — только если пользователь просит или если материала мало
  (тогда разные темы и разные хуки).
- Разнообразь и остальное: длина (10–60 с), раскладка (stream / blur / crop / смена по
  сегментам), начало (реплика, вопрос, момент из игры, лицо), формула подписи.
- Одна и та же сцена не попадает в два клипа (кроме суперката).
- Если пользователь задал пропорцию («10 нарезок: 2 сложные, 3 средние, остальные простые») —
  делай её. Если не задал — смешивай: примерно четверть склеек, треть средних форматов
  (подрезка, момент → реакция, переобувка, эскалация), остальное — цельные отрезки, гайды,
  оффтоп, лица.
- В отчёте пиши формат каждого клипа.

**Цельный отрезок должен быть законченным и интересным сам по себе:**
- **Начало** — реплика, которая открывает тему или вопрос («Ребят, знаете, почему…», вопрос
  тиммейта, начало истории). Не с середины мысли, без «ну и вот».
- **Конец** — тема закрылась: панчлайн, вывод, ответ на вопрос, общий смех, переход на другое
  («так, ладно, играем»). Отрежь до перехода. Если разговор просто затухает — ищи конец раньше,
  на последней сильной фразе.
- **Понятен без контекста.** Если нужно знать, что было до, — либо начни раньше, либо это
  материал для другого формата (момент → реакция, сетап → развязка), либо не бери.
- **Держит внимание** всю длину: есть развитие (спор, нарастание, неожиданный поворот), а не
  ровный комментарий матча.
- Длина по содержанию: 15–60 с. Живой диалог может идти и минуту, если не провисает.

**Как искать цельные отрезки.** Отдельно от поиска склеек пройди транскрипт целиком и выпиши
все самодостаточные куски: разговоры не про игру (жизнь, истории, споры с чатом), обсуждения
с тиммейтами, прогнозы и рассуждения со своей логикой, бурные реакции с объяснением.
Признаки границ в транскрипте — пауза 2+ с, смена темы, «так»/«ладно» перед игровым
комментарием. Для каждого куска оцени: законченный? понятен без контекста? есть поворот или
панчлайн? Бери лучшие.

### 0. Лор
Перед работой загляни в `lore/` — там заметки о стримерах и их тиммейтах (кто есть кто,
мемы, внутренние шутки). Всё, что пользователь рассказывает о лоре, сразу дописывай туда.

### 3. Подпись (заголовок) — самое слабое место, читай внимательно
- **Показывается 3–4 с в начале и исчезает** (`title: {duration: 3.5}`). Подпись на весь клип
  пользователю нравится меньше.
- **Подпись не объясняет шутку и не пересказывает клип.** Зритель сам всё поймёт из клипа.
  Подпись добавляет второй слой: парадокс, ироничный ярлык, каламбур, подыгрывание.
- **Не выдавай подкол за факт.** «Мангеку поставил против своей команды» — ложь: это шутка
  тиммейтов. Подпись может подыгрывать абсурду, но не утверждать его всерьёз.
- 2–6 слов, строчными, без точки в конце.
- Формулы, которые РАБОТАЮТ (оценки пользователя):
  - контраст из двух частей: «у них два капитана. слушают ноль» — шедевр;
  - ироничное преувеличение мелочи: «прыгнуть с кустика — задача со звёздочкой» — очень хорошо;
  - ироничный ярлык: «демократия в команде курседа» — шедевр;
  - парадокс: «322 без единой ставки» — норм;
  - конкретная деталь + ирония: «замена из сиэтла, которая не понимает рофлы» — неплохо;
  - мем-формула: «нашли замену. есть нюанс» — неплохо;
  - ироничная оценка поведения человека (ноет на драфте → разносит): «прибеднился перед игрой» —
    очень неплохо.
- Формулы, которые НЕ работают:
  - «когда …» с разжёвыванием («когда тиммейты уже придумали за тебя 322») — «дегенерат делал»;
  - пересказ сюжета («ушёл на свой турнир — получил 322 от своих») — да ещё и непонятая шутка;
  - уточнение очевидного («обвинён в 322. ставок: 0») — всем и так понятно;
  - размытое без зацепки («курсед перед каждой игрой:», «классика: «меня высушат в ноль»»);
  - ярлык не в тему («главный пессимист команды», «первый легионер в составе» — не попали в суть);
  - рассказчик-дед («и вот последняя драка», «смотрите что было»), КАПС-кликбейт.
- **Часто лучшая подпись — фраза из самого клипа, которая потом становится иронией.**
  Пример: в клипе «сделайте чаёк, сейчас всё чётенько будет» → проигрыш. Подпись
  «всё под контролем» — норм, но «сейчас всё чётенько будет» — лучше: своя фраза героя
  звучит смешнее любого пересказа. Ищи такие цитаты в первую очередь.
- Предлагай пользователю 2–3 варианта подписи на клип и отмечай свой фаворит.

### 4. Эффекты — только по делу
- **Без слоумо-интро** и прочего «колхоза».
- **Зум — только на конфуз**: когда нужно показать, где именно что-то пошло не так
  (неудачный прыжок, промах, смерть). Не зумь просто «для динамики».
- Надписи `text:` на сегментах — редко, только если без них непонятно.
- Прогресс-бар — по желанию пользователя.

### 5. Субтитры
- **Не выдумывай.** Неразборчивое — в `subs_skip`. Где модели расходятся (одно слово
  распознаётся по-разному в разных прогонах) — убирай слово.
- Ошибки распознавания правь `subs.replace` (ники: шегетсу → Шигетсу, мангелка → мангеку).
- После рендера выпиши текст субтитров из `out/<id>.ass` и вычитай его глазами.

### 6. Что заходит в доте/стримах
Рофлы и подколы внутри команды, конфликты/«капитан, которого никто не слушает», тиммейт
не понимает очевидного, сетап-развязка (ноет → разносит), замены и случайные люди в команде,
реакции на донаты/чат, фейлы. Драки без шутки и контекста — слабые клипы.

Не бери моменты с личными данными (номера, адреса, лица случайных людей в IRL) и откровенно
нарушающие правила платформ.

## Раскладки

- `stream` — вебка сверху (`top_height` px), геймплей снизу. Для стримов с вебкой — по умолчанию.
  `game` и `game_focus_x` — какую часть игры показать (для доты центр экрана — где герой).
- `blur` — весь кадр по центру на размытом фоне. Когда важен весь экран (карта, драфт, катсцены)
  или нет вебки. `zoom: 1.2` подрежет края.
- `crop` — вертикальная вырезка из кадра (`rect`, `focus_x`). Для IRL/говорящей головы.

## Правила

- Не трогай исходники и чужие файлы вне `work/`. Готовые клипы — только в `work/<проект>/out/`.
- Длинные операции (fetch, transcribe, render многих клипов) запускай в фоне и следи за выводом.
- Авторские права: напомни пользователю один раз, если он режет чужой контент для монетизации,
  дальше не повторяй.
- Если что-то в пайплайне ломается — чини код в `clipper/`, а не обходи вручную, и коммить фикс.
