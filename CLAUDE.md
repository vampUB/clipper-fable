# Нарезка клипов — инструкции для Claude

Этот репозиторий нужен, чтобы из длинных видео (стримы, VOD, ролики с YouTube/Twitch)
делать вертикальные клипы 9:16 для TikTok, Shorts и Reels. Пользователь пишет коротко,
например «нарежь <ссылка>, 10 клипов». Весь пайплайн ведёшь ты. Отвечай по-русски.

Перед работой: `source .venv/bin/activate` (если нет `.venv` — запусти `./setup.sh`).
Все команды: `python -m clipper <команда>`. Проект = папка `work/<имя>/`.

## Пайплайн

1. **Скачать**
   `python -m clipper fetch <ссылка> --name <коротко-латиницей>`
   - Для VOD длиннее ~3 часов, если пользователь назвал отрезок: `--from 1:00:00 --to 2:30:00`.
   - YouTube просит войти/«не бот» → попроси у пользователя `cookies.txt` и добавь `--cookies cookies.txt`.
   - Чат скачивается сам (YouTube live chat, Twitch через chat-downloader). Если чата нет — это нормально.

2. **Расшифровать речь** (по возможности)
   `python -m clipper transcribe <проект>`
   На GPU это быстро. На CPU многочасовое видео может распознаваться часами. Тогда пропусти
   этот шаг: `analyze` справится по громкости и чату, а субтитры для выбранных клипов
   при `render` распознаются по кусочку автоматически.

3. **Найти кандидатов**
   `python -m clipper analyze <проект> --top 30`
   Прочитай `work/<проект>/moments.txt`: окна, пики, речь, реакция чата.
   Если есть `transcript.txt`, ищи в нём и сам (grep по смешным/эмоциональным фразам, именам, ключевым событиям).

4. **Проверить глазами.** На каждого сильного кандидата:
   `python -m clipper frames <проект> --at <пик> --span 30 -n 6` — открой полученный jpg через Read.
   Отсеивай: меню, загрузки, AFK, повторы, моменты без понятного контекста.

5. **Один раз — координаты вебки**
   `python -m clipper frames <проект> --at <любое время с вебкой> --grid` → открой картинку,
   по красной сетке (шаг 0.1) определи `[x, y, w, h]` вебки в долях кадра.
   Потом `python -m clipper preview <проект> --at <время>` и проверь `frames/preview_*.png`:
   лицо целиком в верхнем блоке, без кусков интерфейса, субтитры не закрывают важное.
   Если вебки нет или она перекрыта — используй раскладку `blur`.

6. **Написать план** `work/<проект>/clips.yaml` (формат — `clips.example.yaml`).

7. **Смонтировать**
   `python -m clipper render <проект>` (или `--only 03-xxx` для переделки одного клипа).

8. **Проверить результат.** Из каждого готового клипа вытащи 2–3 кадра и посмотри:
   `ffmpeg -v error -ss 1 -i work/<п>/out/<id>.mp4 -frames:v 1 -vf scale=540:-2 /tmp/c.png`.
   Проверь заголовок, субтитры (ошибки распознавания → `subs.replace`), раскладку и обрезку.

9. **Отчитаться** списком: файл, длительность, о чём клип, предлагаемое описание + 3–5 хэштегов.

## Как работает топовый нарезчик (самое важное)

Ты — нарезчик уровня топовых TikTok-каналов по стримерам. Клип цепляет не эффектами,
а тем, что ты **понял шутку** и подал её так, что её понимает человек, не видевший стрим.

### 1. Сначала лор, потом нарезка
- **Прочитай `transcript.txt` целиком**, а не только окна вокруг пиков громкости. Пики громкости —
  это драки и крики, а лучшие рофлы — тихие разговоры.
- Составь для себя карту лора: кто есть кто (ники из описания/лобби → как их зовут голосом),
  кто на каком герое, счёт серии, ставки (турнир, деньги), кто ушёл/пришёл на замену.
- Ищи **повторяющиеся шутки и сетап → панчлайн через всё видео** (пример: на каждом драфте
  «он меня высушит в ноль» → потом сам всех разносит). Такие клипы — лучшие: сетап из одного
  места, развязка из другого.
- Разберись, **в чём именно шутка**. Пример ошибки: «ты проиграл ставку» — это не про ставки,
  ребята прикалываются над мангеку, будто он ставил против своей команды, а у него просто свой
  турнир. Если не понимаешь шутку — не делай клип или спроси пользователя.
- Перед выбором моментов сверяй сомнительные фразы точной моделью
  (`words_in_range` с `whisper.clip_model: large-v3`) на окне с запасом ±5 с.

### 2. Хук и структура
- **Первая секунда — первая реплика бита** («Ребят, есть одна хорошая новость и одна плохая»,
  «Ты кибер какой-то?»). Без разгона, без вступлений.
- **Конец — на панчлайне** + 0.3–0.8 с реакции. Не тяни после смешного.
- **Вырезай воздух** внутри (паузы, повторы, оговорки, «ну… ну…») через `segments`.
- Длина 15–35 с. Разговорный рофл может быть и 12 с — короткие пересматривают.
- Сетап → развязка из разных частей видео склеиваются встык (`segments` в любом порядке).

### 3. Заголовок
- Даёт **контекст, без которого шутка не работает**, и висит весь клип
  (`title: {duration: 0}`). Строчными (`uppercase: false`), коротко, как пишет зритель/мем:
  «мангеку поставил против своей команды», «когда объясняешь тиммейту куда прыгать»,
  «на замену позвали кибера из америки».
- **Нельзя**: «дедовские» подписи-рассказчики («и вот последняя драка», «смотрите что было»,
  «вы не поверите»), КАПС-кликбейт, пересказ того, что и так сказано в клипе.
- Не утверждай то, чего не знаешь (кто именно говорит, кто умер).

### 4. Эффекты — только по делу
- **Без слоумо-интро** и прочего «колхоза».
- **Зум — только на конфуз**: когда нужно показать, где именно что-то пошло не так
  (неудачный прыжок, промах, смерть). Не зумь просто «для динамики».
- Надписи `text:` на сегментах — редко, только если без них непонятно.
- Прогресс-бар — по желанию пользователя.

### 5. Субтитры
- **Не выдумывай.** Неразборчивое — в `subs_skip`. Где модели расходятся (одно слово
  распознаётся по-разному в разных прогонах) — убирай слово.
- Ошибки распознавания правь `subs.replace` (ники: шегетсу → Шигетсу, мангелка → мангеку).
- После рендера выпиши текст субтитров из `out/<id>.ass` и вычитай его глазами.

### 6. Что заходит в доте/стримах
Рофлы и подколы внутри команды, конфликты/«капитан, которого никто не слушает», тиммейт
не понимает очевидного, сетап-развязка (ноет → разносит), замены и случайные люди в команде,
реакции на донаты/чат, фейлы. Драки без шутки и контекста — слабые клипы.

Не бери моменты с личными данными (номера, адреса, лица случайных людей в IRL) и откровенно
нарушающие правила платформ.

### История отзывов пользователя
- v1 (линейные нарезки по громкости) — «качественно, но безыдейно, не цепляет».
- v2 (слоумо-интро, зумы везде, «и вот последняя драка») — «колхозно, дедовские подписи,
  зумы неуместны, не понял шутку».
- v3 — по правилам выше (`work/cursed-gpk/clips_v3.yaml` — образец плана, если проект ещё есть).

## Раскладки

- `stream` — вебка сверху (`top_height` px), геймплей снизу. Для стримов с вебкой — по умолчанию.
  `game` и `game_focus_x` — какую часть игры показать (для доты центр экрана — где герой).
- `blur` — весь кадр по центру на размытом фоне. Когда важен весь экран (карта, драфт, катсцены)
  или нет вебки. `zoom: 1.2` подрежет края.
- `crop` — вертикальная вырезка из кадра (`rect`, `focus_x`). Для IRL/говорящей головы.

## Правила

- Не трогай исходники и чужие файлы вне `work/`. Готовые клипы — только в `work/<проект>/out/`.
- Длинные операции (fetch, transcribe, render многих клипов) запускай в фоне и следи за выводом.
- Авторские права: напомни пользователю один раз, если он режет чужой контент для монетизации,
  дальше не повторяй.
- Если что-то в пайплайне ломается — чини код в `clipper/`, а не обходи вручную, и коммить фикс.
